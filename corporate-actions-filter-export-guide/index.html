Vote Tally: Filtering & Exporting the Voter List

This is a hands-on walkthrough of two new tools on the Corporate Action detail page. Everything below is live and clickable — using real sample data — so you can try it exactly as it works in the admin system.

1

Click a tally box

Click Approve, Reject, Not Voted (etc.) to instantly filter the voter list below to just those shareholders.

2

Export what you see

Press Export CSV to download the currently shown (filtered) list as a spreadsheet you can open in Excel.

3

Open an investor

Click any investor’s name to jump straight to their profile.
